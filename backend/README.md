# Backend

API NestJS com Prisma e PostgreSQL. Consulte o [README principal](../README.md) para instalação, execução e testes.

Uso básico: `GET /users/personas` lista as personas de demonstração; `GET /users/me` exige o header `x-user-id`. Essa identidade é simulada, sem login real.
